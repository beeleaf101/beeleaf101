# INSTALL YOUR NEW GITHUB PROFILE 💚

Your GitHub username is `beeleaf101`.

## 1. Create your special profile repository

Go to https://github.com/new and set:
- Owner: `beeleaf101`
- Repository name: **`beeleaf101`** (must match your username exactly)
- Visibility: **Public**

If this repository already exists, use it instead; back up its current README before replacing it.

## 2. Upload these files

From this folder, put all of the following inside the `beeleaf101` repository:

- `README.md`
- `assets/` (all the .svg files)
- `profile-3d-contrib/profile-night-green.svg` (placeholder shown until first run)
- `.github/workflows/3d-contributions.yml` (the workflow file)

**Important:** Hidden directories beginning with a dot, such as `.github`, may be hidden by your file manager. Make sure to upload the actual workflow file at the exact path above. The easiest way is to unzip locally, then use Git to push the whole folder.

## 3. Turn on the real contribution city

1. Open the new `beeleaf101` repository > **Settings** > **Actions** > **General**.
2. Under **Workflow permissions**, select **Read and write permissions** and save (if your GitHub settings provide this option). This lets the workflow commit the generated image.
3. Open the **Actions** tab.
4. Select **GitHub Profile 3D Contributions** > **Run workflow**.
5. Wait for the workflow to complete successfully, then refresh https://github.com/beeleaf101.

The city visualization will replace the starter illustration with your *real GitHub activity*. It refreshes daily after that.

## 4. Notes

- The animated SVG header, technology panel, and project cards work without JavaScript.
- The activity statistics and languages cards are provided by the external `github-readme-stats` service and may temporarily fail or hit rate limits. The GitHub 3D city is generated by a workflow in your own repository.
- The card labeled NOMOU links to the public `nomou-website` repo; private projects were deliberately excluded.
- All images are SVGs and can be recolored or edited later.
- The profile README appears on your GitHub profile only when the repository is **public**, its name matches your GitHub username, and it contains `README.md` at the root.
